# GEO2102 Group 3 Hostel Assignment

## Group 3 Java Hostel Data Processing Project

This project was developed using Apache NetBeans and Java.

## Group Assignment

The program stores and processes hostel information for hostels H11-H15.

## Data Stored

The program stores:

- Hostel ID
- Hostel Name
- Accommodation Type
- Rental Price
- Occupancy Status
- Latitude
- Longitude

## Processing Performed

The program:

1. Stores the hostel records as Hostel objects.
2. Stores the objects in an array.
3. Processes the records using a loop.
4. Determines whether a hostel is fully occupied.
5. Calculates the average rental price.
6. Counts fully occupied hostels.
7. Counts hostels that are not fully occupied.
8. Displays the results.
